# Punta Pacífico | Tour virtual de Legacy Capital

Sitio interactivo para presentar los prototipos de 2 y 3 recámaras de Punta Pacífico, Ensenada, Baja California.

El tour utiliza imágenes, renders y planos extraídos de materiales oficiales y publicados como una experiencia visual orientada a compradores. Las vistas son ilustrativas y no constituyen una reconstrucción BIM ni un recorrido 3D de geometría verificada.

Los archivos fuente del tour están guardados en la carpeta `17. Tour Virtual Legacy Capital` del Google Drive del proyecto.
